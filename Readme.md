# Development Board

## Description
This is a development board PCB made with a bare bones ESP32-C3. It can support wireless connections which is useful. It contanis three pin headers, with one containing power supply gpio. THe other one is GPIO only and lastly the 2 pins are for TXD and RXD. Uses USB-C to get power.
